# Project Description

## **Project Name**

# **EVENTO \- Smart Multi-Vendor Event Planning & Booking Platform**

---

# **Project Overview**

EVENTO is a next-generation multi-vendor event planning platform designed to simplify the complete event booking process. Instead of contacting multiple vendors individually, customers can plan, customize, estimate, and book their entire event through a single platform.

The platform supports **zone-wise pricing**, **custom event configuration**, **predefined packages**, **real-time budget calculation**, and **centralized vendor management**. Customers only interact with services and packages, while the platform's administrators manage vendor assignments behind the scenes.

This creates a transparent, scalable, and user-friendly ecosystem for customers, vendors, and administrators.

---

# **Mission**

To simplify event planning by providing a centralized platform where customers can easily customize every aspect of their event, receive transparent real-time pricing, and complete bookings while the platform intelligently manages vendor operations behind the scenes.

---

# **Vision**

To become Bangladesh's leading event technology platform by building the country's largest digital ecosystem that connects customers with trusted event service providers through intelligent automation, zone-based pricing, configurable services, and seamless booking experiences.

---

# **Business Model**

EVENTO operates as a **Managed Multi-Vendor Event Platform**.

Unlike traditional marketplaces, customers never browse or select vendors.

Instead, the workflow is:

Customer selects Zone

↓

Customer selects Event Type

↓

Customer chooses Package  
OR  
Uses Smart Calculator

↓

Customer selects only required services

↓

Customer configures each selected service

↓

System calculates estimated budget

↓

Customer submits booking

↓

Admin reviews booking

↓

Admin assigns vendors

↓

Vendors complete assigned services

↓

Customer reviews EVENTO

This business model ensures:

* Centralized operational control  
* Consistent service quality  
* Transparent pricing  
* Better customer experience  
* Efficient vendor management

---

# **Core Concept**

The platform provides **two independent booking experiences**.

## **1\. Package Booking**

Customers browse ready-made event packages from a dedicated Package page.

Example:

* Wedding Basic Package  
* Wedding Premium Package  
* Reception Package  
* Holud Package  
* Birthday Package  
* Corporate Package

Customers can optionally customize services included in the selected package before confirming the booking.

---

## **2\. Smart Event Calculator**

Customers create their own event from scratch.

Instead of forcing customers to go through every service, the calculator first asks which services are required.

Only the selected services are displayed for configuration.

Each configured service updates the estimated budget in real time.

# **Updated Enterprise Goal**

EVENTO is not a traditional vendor marketplace. It is a **Managed Event Operating System (Event OS)** that centralizes package booking, configurable event planning, zone-based pricing, booking management, vendor operations, payments, customer support, analytics, and business administration into one scalable platform. Customers interact only with services and packages, while EVENTO manages all vendor coordination internally to ensure a seamless, standardized, and high-quality event experience.

# **Business Logic**

* Customer প্রথমে **Zone** নির্বাচন করবে।  
* নির্বাচিত Zone অনুযায়ী শুধু সেই Zone-এর **Packages** দেখানো হবে।  
* Smart Calculator-এ সব Service-এর **Price Zone অনুযায়ী** লোড হবে।  
* একই Service-এর আলাদা Zone-এ আলাদা Price থাকবে।  
* Vendor Assignment-ও Zone অনুযায়ী হবে; Admin শুধুমাত্র ঐ Zone-এ Available Vendor-দের Assign করতে পারবে।  
* ভবিষ্যতে নতুন Zone যোগ করলে Service, Package, Pricing ও Vendor Availability সহজেই extend করা যাবে।
